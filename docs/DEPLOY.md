# النشر أونلاين (الخادم الكامل) — دليل خطوة بخطوة

**الهدف:** رابط واحد (مثلاً `https://orbital-academy.up.railway.app`) يعمل عليه الموقع والـ API معاً، فيحصل الطلاب على:
لوحة متصدرين مشتركة · حسابات تعمل من أي جهاز · تسجيل Google · مدرس ذكي حقيقي (LLM) · لوحة المعلم.

> **صدق في التوثيق:** جرّبت تشغيل الخادم بنفس بنية الـ container (فقط الملفات التي ينسخها `Dockerfile`، وقاعدة البيانات على مجلد منفصل، وإعادة تشغيل) ونجح. لكني **لم أبنِ صورة Docker** (الـ daemon غير متاح في بيئتي) ولم أنشر على أي منصة فعلياً. الإعدادات (`Dockerfile`, `render.yaml`, `fly.toml`) مكتوبة بحسب توثيق المنصات، وقد تحتاج تعديلاً بسيطاً عند أول نشر. أسعار المنصات وخططها المجانية **تتغير** — راجعها قبل الاشتراك.

---

## 0) ما الذي يجب فهمه أولاً (3 نقاط)
1. **الخادم يحتاج قرصاً دائماً (Volume/Disk).** الحسابات والنقاط في ملف SQLite. على الخطط المجانية التي **بدون قرص دائم** تُمسح كل البيانات عند كل إعادة نشر أو نوم الخدمة. لذلك اختر منصة/خطة فيها Volume.
2. **أسرار المفاتيح تُوضع في إعدادات المنصة فقط (Environment Variables)** — لا تكتبها أبداً في الكود ولا ترفعها على GitHub.
3. الخادم يعمل على أي منصة تشغّل Docker أو Node بنسخة **22.13 أو أحدث**، ويقرأ `PORT` من المنصة تلقائياً.

## 1) المتغيرات (Environment Variables)
| المتغير | مطلوب؟ | الوظيفة |
|---|---|---|
| `AUTH_SECRET` | **نعم** | نص عشوائي طويل لتوقيع جلسات الدخول. ثابت — لو تغيّر يخرج كل المستخدمين. ولّده: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
| `DATA_DIR` و `DB_FILE` | في Docker يُضبطان تلقائياً | `/data` و `/data/orbital.db` — **يجب أن يكون `/data` هو مسار الـ Volume** |
| `GROQ_API_KEY` (مجاني) أو `GEMINI_API_KEY` أو `OPENROUTER_API_KEY` أو `OPENAI_API_KEY` … | للمدرس الذكي | واحد يكفي (انظر §5). بدونه يعمل شرح المنهج المحلي |
| `GOOGLE_CLIENT_ID` | لتسجيل Google | ليس سراً (انظر §4) |
| `PORT` | لا | تضبطه المنصة |

## 2) الخيار الأسهل: Railway
1. ارفع المشروع على ريبو GitHub (الفرع `main`).
2. في Railway: **New Project → Deploy from GitHub repo** → اختر الريبو. سيكتشف `Dockerfile` ويبني تلقائياً.
3. افتح الخدمة → **Variables** → أضف `AUTH_SECRET` (القيمة المولّدة) وأضف مفتاح الـ AI و`GOOGLE_CLIENT_ID` عند جاهزيتهما.
4. **Volumes → New Volume** → Mount path: **`/data`**.
5. **Settings → Networking → Generate Domain** لتحصل على الرابط `https://…up.railway.app`.
6. افتح `https://الرابط/api/health` — يجب أن ترى `"ok":true` وعدد الأسئلة `16241`.

## 3) بدائل
### Render
- **New → Blueprint** → اختر الريبو؛ سيقرأ `render.yaml` (يُنشئ خدمة Docker + قرصاً 1GB على `/data` + `AUTH_SECRET` تلقائياً). القرص يتطلب خطة مدفوعة.
- بعد الإنشاء: **Environment** → أضف `GEMINI_API_KEY` و`GOOGLE_CLIENT_ID`.

### Fly.io (سطر أوامر)
```bash
# بعد تثبيت flyctl وتسجيل الدخول:  fly auth login
fly launch --no-deploy --copy-config      # غيّر app في fly.toml لاسم فريد
fly volumes create orbital_data --size 1  # القرص الدائم (مرة واحدة)
fly secrets set AUTH_SECRET=<القيمة_المولّدة> GEMINI_API_KEY=<مفتاحك>
fly deploy
```
> Fly يربط القرص بجهاز واحد: لا تزِد عدد الأجهزة عن 1 (`fly scale count 1`).

### جهاز/VPS خاص (مدرسة أو سيرفر)
```bash
docker build -t orbital-academy .
docker run -d --restart=always -p 8080:8080 -v orbital_data:/data \
  -e AUTH_SECRET=<القيمة_المولّدة> -e GEMINI_API_KEY=<مفتاحك> orbital-academy
```
وضع خلفه Caddy أو Nginx لتفعيل HTTPS (Google يشترط HTTPS).

## 4) تسجيل Google (خطوة بخطوة)
1. افتح **console.cloud.google.com** → أنشئ مشروعاً (أو اختر موجوداً).
2. **APIs & Services → OAuth consent screen**: اختر *External*، اكتب اسم التطبيق (Orbital Academy)، بريدك، وأضف نطاق موقعك. (للتجربة يمكن إبقاؤه في وضع *Testing* وإضافة بريدات المختبرين.)
3. **Credentials → Create credentials → OAuth client ID** → النوع **Web application**.
4. **Authorized JavaScript origins**: أضف رابط موقعك بالضبط، مثل `https://orbital-academy.up.railway.app` (بدون `/` في النهاية، وبـ https).
5. انسخ **Client ID** (ينتهي بـ `.apps.googleusercontent.com`) وضعه في متغير `GOOGLE_CLIENT_ID` ثم أعد تشغيل الخدمة.
6. افتح الموقع: ستجد شاشة الدخول بتصميمها الأصلي (اسم المستخدم + الصف + زر Google). عند أول دخول بـ Google يُنشئ الخادم الحساب بالصف المختار، ويستخدم **اسم المستخدم الذي كتبه الطالب** (أو اسماً عشوائياً مثل `pilot4821` إن تركه فارغاً). **لا يُعرض اسم حساب Google الحقيقي** على لوحة المتصدرين، حمايةً للقاصرين.

> الخادم يتحقق من توكن Google عبر `oauth2.googleapis.com/tokeninfo` ويفحص أن `aud` يطابق `GOOGLE_CLIENT_ID`. **لم أستطع تجربة هذا التدفق حقاً** (يحتاج Client ID حقيقياً ومتصفحاً على نطاقك) — اختبره بنفسك أول مرة. إن ظهر `origin_mismatch` فالرابط في الخطوة 4 لا يطابق رابط موقعك حرفياً.

## 5) المدرس الذكي (LLM) — **مجاناً بدون دفع**
ضع **مفتاحاً واحداً على الأقل** في Railway ← Variables. إن وضعت أكثر من واحد يجرّبهم الخادم بالترتيب (المجاني أولاً) وينتقل للتالي تلقائياً لو فشل أحدهم (حصة منتهية مثلاً)، ولو فشلوا كلهم يعود لشرح المنهج المحلي — اللعبة لا تتعطل أبداً.

| المزوّد | مجاني؟ | من أين المفتاح | المتغير | النموذج الافتراضي |
|---|---|---|---|---|
| **Groq** ⭐ الأسهل | نعم، بدون بطاقة | console.groq.com ← API Keys | `GROQ_API_KEY` | `llama-3.3-70b-versatile` |
| Cerebras | نعم | cloud.cerebras.ai | `CEREBRAS_API_KEY` | `llama-3.3-70b` |
| OpenRouter | نماذج `:free` | openrouter.ai/keys | `OPENROUTER_API_KEY` | `meta-llama/llama-3.3-70b-instruct:free` |
| Google Gemini | مجاني في بعض الحسابات (انظر §7) | aistudio.google.com/apikey | `GEMINI_API_KEY` | `gemini-2.5-flash` |
| Mistral | خطة Experiment المجانية | console.mistral.ai | `MISTRAL_API_KEY` | `mistral-small-latest` |
| OpenAI / Anthropic | مدفوع | platform.openai.com / console.anthropic.com | `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` | `gpt-4o-mini` / `claude-haiku-5-5` |
| **أي مزوّد متوافق مع OpenAI** | حسب المزوّد | — | `AI_API_KEY` + `AI_BASE_URL` + `AI_MODEL` | — |

**أسرع طريقة (دقيقتان):**
1. ادخل console.groq.com بحسابك ← **API Keys** ← **Create API Key** ← انسخ المفتاح.
2. Railway ← خدمتك ← **Variables** ← **New Variable**: الاسم `GROQ_API_KEY` والقيمة المفتاح ← احفظ (يُعاد النشر تلقائياً).
3. افتح `/api/health` — يجب أن ترى `"ai":"groq:llama-3.3-70b-versatile"`.
4. أجب إجابة خاطئة عمداً ← تظهر شارة **✨ groq** في نافذة المدرس.

- يمكن تغيير النموذج بـ `GROQ_MODEL` / `GEMINI_MODEL` / `OPENROUTER_MODEL` … ، وعنوان الخدمة بـ `<NAME>_BASE_URL` (مثل `GROQ_BASE_URL`).
- `AI_PROVIDER=gemini` (مثلاً) يجعل مزوّداً معيّناً أولاً.
- **لا تكتب المفتاح في الشات ولا في الكود** — فقط في Variables. إن ظهر مفتاحك في أي مكان عام فاحذفه من موقع المزوّد وأنشئ غيره.
- الحدود المجانية تتغير وقد تكفي عشرات الطلاب لا آلاف؛ كل خطأ يُرسل طلباً قصيراً واحداً ثم يُخزَّن الرد لإعادة استخدامه، والمحادثة محدودة بعدد الطلبات للطالب في الدقيقة.
- **الخصوصية:** يُرسل للـ LLM نص السؤال والصف والخيارات فقط — **لا اسم الطالب ولا بريده**.

## 6) اختبار بعد النشر (5 دقائق)
1. `https://الرابط/api/health` ← `ok:true`، `questions:16241`، و`ai` يظهر اسم المزوّد (وليس `null`)، و`google` يظهر الـ Client ID.
2. سجّل حساب طالب من هاتفك وآخر من حاسوب → افتح لوحة المتصدرين: يجب أن يظهر الاثنان.
3. أجب إجابة خاطئة عمداً ← يجب أن تظهر شارة **✨ Gemini/OpenAI/Claude** في نافذة المدرس (وليس «شرح المنهج (محلي)»).
4. اضغط «اسأل المدرس» قبل الإجابة ← يشرح الفكرة **دون كشف الحل**.
5. أعد نشر الخدمة (Redeploy) ثم تأكد أن الحسابات والنقاط ما زالت موجودة (دليل أن الـ Volume يعمل).
6. سجّل حساب معلم → أنشئ فصلاً → سجّل طالباً بكود الفصل → تظهر بياناته للمعلم.

## 7) مشاكل شائعة
| العَرَض | السبب والحل |
|---|---|
| الصفحة لا تفتح / 502 | الخادم لا يستمع على `PORT` المنصة (يستمع تلقائياً) — راجع سجل التشغيل. تأكد أن النسخة Node ≥ 22.13 (الـ Dockerfile يستخدم 22). |
| الحسابات تختفي بعد كل نشر | لا يوجد Volume على `/data`. أضفه (§2–3). |
| الجميع يُخرَجون من حساباتهم بعد النشر | `AUTH_SECRET` غير ثابت — ضعه في المتغيرات. |
| المدرس يقول «شرح المنهج (محلي)» رغم وجود مفتاح | المفتاح خطأ أو بلا رصيد أو النموذج غير متاح — ابحث في السجل عن `tutor fallback:`. |
| المدرس «محلي» والسجل فيه `gemini_403 … free tier is not available for this project` | المفتاح سليم لكن جوجل ترفض الخطة المجانية لهذا المشروع/الحساب. الحلول: (أ) فعّل الفوترة للمشروع من aistudio.google.com/billing وضع حداً للإنفاق، أو (ب) أنشئ المفتاح من حساب/مشروع آخر مسموح له بالخطة المجانية، أو (ج) استخدم مزوّداً آخر (انظر أدناه). |
| زر Google لا يظهر | `GOOGLE_CLIENT_ID` غير مضبوط (أعد تشغيل الخدمة بعد ضبطه). |
| `origin_mismatch` من Google | الرابط في *Authorized JavaScript origins* لا يطابق رابط الموقع. |

## 8) قبل استخدامه مع طلاب حقيقيين
- **موافقة المدرسة وأولياء الأمور** (وIRB إذا كان بحثاً علمياً)، خصوصاً أن المستخدمين قاصرون.
- اطلب من الطلاب استخدام **أسماء مستخدم غير حقيقية** (لوحة المتصدرين تعرض اسم المستخدم/الاسم المعروض لأي مستخدم مسجّل).
- خذ **نسخة احتياطية** دورية من `orbital.db` (من لوحة المنصة أو `fly ssh sftp`) — أو اعتمد على تصدير CSV من لوحة المعلم.
- راقب الاستهلاك (الأسئلة والـ LLM) في الأسبوع الأول قبل التوسع.

## 9) مزوّد ذكاء اصطناعي آخر
أي خدمة تتبع واجهة OpenAI تعمل بثلاثة متغيرات (بدون تغيير الكود): `AI_API_KEY` و`AI_BASE_URL` (مثل `https://host/v1`) و`AI_MODEL`. جرّب دائماً بإجابة خاطئة عمداً وتأكد أن الشارة في نافذة المدرس **ليست** «شرح المنهج (محلي)». الأسعار والحدود المجانية تتغير — راجع موقع المزوّد.
