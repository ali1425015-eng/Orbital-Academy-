# ORBITAL ACADEMY v7.0 — أكاديمية المدار

**منصة تعليمية بأسلوب الألعاب (Gamified Learning Platform).** المركبة الفضائية مجرد إطار درامي: لكي تُصلح أي عطل في المركبة، يجب أن تجيب عن أسئلة من **منهجك الدراسي** (رياضيات، علوم/فيزياء، إنجليزي، نحو عربي — من الصف الأول الإعدادي حتى الثالث الثانوي).
صُممت لمواجهة **ضعف التركيز والتشتت** المرتبطين بمنصات التواصل: مهام قصيرة، رصد التخمين السريع، إيقاف تلقائي عند مغادرة التطبيق، واستراحات تركيز يقررها نموذج تعلم آلي.

> A gamified, adaptive learning platform. A space-ship survival game is the shell; every crisis is a short curriculum quiz. Adaptive engine (Elo + Bayesian Knowledge Tracing + spaced repetition), an ML focus model, an LLM AI tutor, accounts, leaderboards and a teacher dashboard.

## الجديد في v7.0
- **واجهة احترافية جديدة** (فاتحة، قائمة جانبية، كروت) على الكمبيوتر والموبايل.
- **العربية / English**: زر تبديل اللغة في كل الشاشات، والاتجاه يتقلب تلقائياً (RTL/LTR). المدرس الذكي يشرح بلغة الواجهة.
- **المادة تُختار مرة واحدة** قبل المهمة، والمدة إما **بالوقت** (3/5/10 دقائق) أو **بعدد الأسئلة** (10/15/20).
- **وضع «تعلّم حر» (Learning)** يُختار من قائمة الصف: 4 مواد خارج المنهج — **IQ والمنطق، الإنجليزية، العلوم، الرياضيات** — بالعربي والإنجليزي حسب لغة الواجهة (7,705 سؤال)، ولا تظهر إلا في هذا الوضع. طلاب المنهج لا يرون إلا مواد منهجهم ومن صفهم فقط.

## التثبيت بملف واحد / Single-file install
| الملف | الاستخدام |
|---|---|
| `orbital-academy.html` | افتحه بالضغط مرتين في أي متصفح حديث — يعمل بدون إنترنت وبدون تثبيت (كل البيانات على الجهاز) |
| `orbital-academy-server.js` | `node orbital-academy-server.js` ← النسخة الكاملة بالخادم على http://localhost:8080 (يحتاج Node.js 22.13+ فقط) |

يُبنى الملفان من المشروع بالأمر `npm run bundle` (يظهران في مجلد `dist/`).

## التشغيل السريع / Quick start

**المتطلبات:** Node.js **22.13 أو أحدث** فقط (لا توجد مكتبات لتثبيتها — قاعدة البيانات SQLite مدمجة في Node).

```bash
cd orbital-academy
npm start
```
ثم افتح **http://localhost:8080**

- بنك الأسئلة وقاعدة البيانات جاهزان داخل الملف. لإعادة توليد البنك والتحقق منه: `npm run build`
- لاختبار كل شيء: `npm test` (التحقق من 23,946 سؤالاً + 42 اختبار API كامل)
- حسابات تجريبية للعرض (لوحة متصدرين + لوحة معلم ممتلئة): `npm run demo-seed` — كلمة المرور `demo1234`، المعلم `demo_teacher`، كود الفصل `DEMO10`

**بدون خادم (Offline):** افتح `index.html` مباشرة، أو ارفع المشروع كما هو على GitHub Pages. التطبيق يكتشف غياب الخادم ويعمل بالكامل داخل المتصفح (الحسابات والنقاط محفوظة على الجهاز نفسه، والمدرس الذكي يستخدم شرح المنهج المحلي).

### تفعيل المدرس الذكي (LLM) وتسجيل Google
انسخ `.env.example` واملأ ما تحتاجه، ثم شغّل الخادم بهذه المتغيرات:
```bash
GEMINI_API_KEY=... npm start          # أو OPENAI_API_KEY=...  أو ANTHROPIC_API_KEY=...
GOOGLE_CLIENT_ID=xxxx.apps.googleusercontent.com npm start
```
المفتاح يبقى على الخادم ولا يصل للمتصفح أبداً. لو فشل الاتصال بالـ LLM يرجع النظام تلقائياً لشرح المنهج المحلي.

## المكونات الأربعة المطلوبة

### 1) قاعدة بيانات المناهج (Question Bank)
- `generator/` يولد الأسئلة بخوارزميات ذات بذرة ثابتة (نفس البنك في كل مرة). كل سؤال بالمخطط المطلوب:
  `questionId, gradeLevel, subject, difficulty, questionText, options[4], correctOptionIndex, conceptTag` + `explanation` + `optionNotes`.
- **كل اختيار خاطئ ناتج عن خطأ شائع محدد** (مثلاً جمع المقامات، نسيان قلب المتباينة، الخلط بين التصريف الثاني والثالث، رفع خبر كان) ومعه شرح لسبب الخطأ — هذا ما يجعل المدرس الذكي دقيقاً حتى بدون إنترنت.
- `tests/test-bank.js` يتحقق من كل سؤال (4 خيارات مختلفة، فهرس صحيح، شرح لكل خطأ...) **ويعيد حل 4,600+ سؤال حسابي وفيزيائي بمحلل مستقل** للتأكد من صحة الإجابة.
- التخزين: SQLite (`server/db.js`)، والدالة `fetchQuestions(gradeLevel, subject, limit)` = `GET /api/questions`.

|---|---|---|
| الرياضيات | 6,051 | الكسور، المعادلات، فيثاغورس، المميز، المتتابعات، اللوغاريتمات، النهايات، التفاضل والتكامل |
| العلوم/الفيزياء | 4,126 | السرعة، الكثافة، نيوتن، الشغل والقدرة، قانون أوم، المقاومات، الموجات، القوة المغناطيسية، كولوم، المكثف، فارادي، علوم الفضاء |

### 2) الحسابات والتقدم (Auth & Progression)
- تسجيل/دخول بكلمة مرور (scrypt) + **Google Sign-In** (التحقق من ID token على الخادم) + جلسات موقّعة HMAC.
- نقاط XP، مستويات ورتب (متدرّب ← أدميرال المجرّة)، أيام متتالية، 9 أوسمة، لوحة متصدرين (عام / الصف / الفصل / الأسبوع).
- **الخادم هو من يصحح الإجابة ويحسب النقاط** (الطالب لا يستلم مفتاح الإجابة)، مع حماية من الغش: لا يمكن الإجابة عن سؤال لم يُرسل، ولا مرتين، والوقت يُقاس على الخادم، ومكافأة المهمة تتناسب مع مدتها الفعلية.
- لوحة المعلم: إنشاء فصل بكود، متابعة الدقة والتركيز والتخمين السريع وأضعف المفاهيم لكل طالب، تصدير CSV.

**الأسئلة من سنة الطالب فقط:** يسحب الخادم والتطبيق أسئلة الصف الدراسي المسجَّل للطالب بالضبط (طالب الصف الأول الثانوي لا يرى أسئلة إعدادي ولا من تانية ثانوي). الاختبار الآلي `tests/test-api.js` يسحب 120 سؤالاً من المواد الأربع ويتأكد أن كلها من الصف نفسه. وخريطة «أي مفهوم في أي صف» في [`docs/CURRICULUM_MAP.md`](docs/CURRICULUM_MAP.md) — **وضعها المطوّر وتحتاج مراجعة معلم المادة** مقابل الكتب الرسمية.

### 3) محرك اللعبة (Core Loop)
`CrisisManager` يطلق عطلاً في نظام من أنظمة المركبة ← النظام يفقد طاقته ← **يختار الطالب بنفسه المادة** التي سيُصلح بها (رياضيات/علوم/إنجليزي/نحو) ويدخل براحته ← سؤال ← `checkAnswer`:
- **صحيح:** +18 للنظام، XP × السلسلة، تحديث الإتقان.
- **خطأ:** −12 + فتح **المدرس الذكي**.
- أدوات: حذف إجابتين (يقرره الخادم)، تلميح القاعدة (نصف النقاط)، مؤقت لكل سؤال.

### 4) المدرس الذكي (AI Tutor)
يظهر المدرس بعد كل إجابة خاطئة، ويمكن للطالب أيضاً **سؤاله قبل الإجابة** (زر «اسأل المدرس» أو مفتاح T) — الخادم هو من يعرف أن السؤال ما زال مفتوحاً، فيمنع الـ LLM من كشف الحل. `server/tutor.js` يرسل للـ LLM: الصف، السؤال، الخيارات، إجابة الطالب، الإجابة الصحيحة، **الخطأ الشائع المتوقع**، وقاعدة المنهج — ويطلب 3 جمل قصيرة بالعربية بأسلوب فضائي مشجع. يظهر الرد بتأثير الكتابة المتتالية مع زر "متابعة"، ويمكن للطالب سؤال متابعة. الردود تُخزّن مؤقتاً لتقليل التكلفة.

## الخوارزميات والتعلم الآلي
| المكوّن | الطريقة | الملف |
|---|---|---|
| مستوى الطالب وصعوبة السؤال | Elo rating (Pelánek 2016) يتحدث بعد كل إجابة | `js/shared/adaptive.js` |
| إتقان كل مفهوم | Bayesian Knowledge Tracing | نفس الملف |
| المراجعة | تكرار متباعد (صناديق Leitner) | نفس الملف |
| اختيار السؤال التالي | أقرب سؤال لنسبة نجاح متوقعة ≈72% ("منطقة التعلم")، ترتفع للأسهل عند انخفاض التركيز | نفس الملف |
| التخمين السريع | عتبة زمن الاستجابة (Wise & Kong 2005) → لا نقاط ولا تحديث للمستوى | `rules.js` |
| نموذج 1: احتمال الإجابة الصحيحة (AUC 0.635) | انحدار لوجستي (9 خصائص) | `ml/train.py` → `model-weights.js` |
| نموذج 2: خطر التشتت في الإجابة التالية (AUC 0.664) | انحدار لوجستي (7 خصائص) → استراحة تنفس 20 ثانية | نفس الملف |

النماذج مدربة على **706,553 إجابة من 2,500 طالب افتراضي** (محاكاة) لأنه لا توجد بيانات صفية حقيقية بعد. التفاصيل والنتائج — بما فيها النتائج غير المؤيدة للفرضية — في [`docs/RESEARCH.md`](docs/RESEARCH.md).

## التشغيل أونلاين على GitHub Pages (بدون خادم)
1. ارفع المشروع على ريبو GitHub (الفرع `main`).
2. من **Settings → Pages**: اختر *Deploy from a branch* ← الفرع `main` ← المجلد `/ (root)` ← Save.
3. بعد دقيقة يفتح الرابط `https://<حسابك>.github.io/<اسم-الريبو>/`.

**ما الذي يعمل على Pages؟** كل اللعبة: الأسئلة (من صف الطالب فقط)، اختيار المادة عند كل عطل، الذكاء التكيفي، نموذج التركيز، الأوسمة، لوحة المعلم. **لكن** الحسابات والنقاط ولوحة المتصدرين تُحفظ **في متصفح كل جهاز على حدة**، والمدرس الذكي يعمل بشرح المنهج المحلي.
**للّوحة المتصدرين المشتركة وتسجيل Google والمدرس الذكي (LLM)** شغّل الخادم (`npm start`) على أي استضافة تدعم Node.js 22.13+ (Render / Railway / Fly.io) — راجع `docs/SETUP.md`. الخادم يخدم نفس الملفات، فيعمل الموقع والـ API على رابط واحد. **الدليل الكامل خطوة بخطوة (Railway / Render / Fly.io، تسجيل Google، مفتاح الـ AI، الاختبار والمشاكل الشائعة): [`docs/DEPLOY.md`](docs/DEPLOY.md)**، وجاهز فيه `Dockerfile` و`render.yaml` و`fly.toml`.

## إعادة إنتاج الدراسة الحاسوبية (≈10 دقائق)
```bash
npm run build                 # توليد البنك + التحقق
npm run sim:dataset           # 2,500 طالب افتراضي → research/sim-dataset.csv
pip install numpy pandas scikit-learn matplotlib
npm run train                 # تدريب النموذجين وتصدير الأوزان
npm run sim:ablation          # مقارنة 5 سياسات على 600 طالب (تصميم مقترن)
npm run figures               # الرسوم البيانية
```
